# CS2 SKINS — Кейсы и Апгрейды

Веб-сайт для открытия кейсов и апгрейда скинов CS2. Демо-проект с красивым дизайном и анимациями.

## Функционал

- **Кейсы** — 6 различных кейсов с разными редкостями и ценами. Рулетка с анимацией при открытии.
- **Апгрейд** — улучшение скинов с системой шансов. Чем дороже цель, тем меньше шанс.
- **Инвентарь** — хранение и продажа выигранных скинов. Фильтрация по редкости.
- **Баланс** — виртуальная валюта для открытия кейсов.
- **Сохранение** — состояние сохраняется в localStorage.

## Дизайн

- Тёмная тема в стиле CS2
- Анимированные частицы на фоне
- Плавные анимации и переходы
- Glassmorphism эффекты
- Адаптивный дизайн (мобильные устройства)
- Цвета редкости скинов (от серого до золотого)

## Технологии

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox, Animations)
- Vanilla JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts (Inter, Orbitron)

## Запуск

Просто откройте `index.html` в браузере. Серверная часть не требуется.

```bash
# Или используйте любой статический сервер:
python3 -m http.server 8080
```
